⛩️ Age of Shoguns is a real-time strategy game set in feudal Japan in 1560, and it runs entirely in your web browser.

Build a village in Kai Province, raise an army of samurai, ashigaru spearmen, archers, sohei monks and mounted samurai, and fight off waves of ronin raiders. To win, destroy the enemy castle, or build the Great Pagoda and hold it for three minutes.

Nothing in the game is a 3D model or texture file. Every castle, tree, villager, horse and suit of armour is generated by code with Three.js.

🎮 What's in the game
• Four ages: Village → Feudal → Castle → Shogunate
• A living town: families, children growing up, festivals, taxes and happiness
• Seasons: cherry blossom, summer green, red autumn maples and winter snow
• Day and night with moonlight, stars, rain and snow
• National borders glowing on the ground, with attrition for soldiers in enemy land
• A cinematic battle cam with slow motion on killing blows
• An opening that flies down from the globe to Japan

🖼️ Classic vs Realistic graphics, switchable at any time with one key (R)
• AgX tone mapping and a film-style colour grade
• Ambient occlusion (GTAO) and height fog that glows toward the sun
• Real reflections on the lake
• Detailed ground with dense grass, ferns, flowers and fallen leaves
• Foot IK on slopes, breathing, footprints, dust and hit knockback
• Depth of field in the battle cam

🛠️ Built with Three.js r170, Vite and Docker
💻 Source code: https://github.com/Subhagatoadak/Age-Of-Shoguns
▶️ Run it yourself: clone the repo, run `docker compose up -d --build`, then open http://localhost:8686
